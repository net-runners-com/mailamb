# mailamb Thunderbird 拡張 インストール・設定手順

対象: 各スタッフPC（Mac / Windows / Linux 共通）  
所要時間: 10分

---

## 事前準備（管理者から受け取るもの）

- [ ] **mailamb-x.y.z.xpi** ファイル（拡張本体）
- [ ] **Worker URL**（例: `https://mailamb.<組織名>.workers.dev`）
- [ ] **API Key**（64文字の英数字）
- [ ] **自分のスタッフID**（例: `tanaka` / `suzuki` / `SK` 等、重複しない識別子）

**メールアカウント**: Thunderbird に業務用の共有メールアカウント（info@〜 等）が既にIMAPで接続されている前提。

---

## STEP 1: Thunderbird プロファイルの場所を確認

TBメニュー → **ヘルプ** → **トラブルシューティング情報** を開く。

「プロファイルフォルダー」の行の **「フォルダーを開く」** をクリック。

ファインダー/エクスプローラーでプロファイルフォルダが開く。この場所のパスをコピーしておく。

例:
- macOS: `/Users/<name>/Library/Thunderbird/Profiles/xxxxxx.default-release/`
- Windows: `C:\Users\<name>\AppData\Roaming\Thunderbird\Profiles\xxxxxx.default-release\`
- Linux: `~/.thunderbird/xxxxxx.default-release/`

---

## STEP 2: 未署名拡張を許可する設定を追加

**STEP 1で開いたプロファイルフォルダ**の中に `user.js` ファイルがあるか確認。

### `user.js` が無い場合（新規作成）

テキストエディタで新規作成、以下の1行を書いて保存:

```
user_pref("xpinstall.signatures.required", false);
```

### `user.js` が既にある場合

末尾に以下の1行を追加して保存:

```
user_pref("xpinstall.signatures.required", false);
```

**この設定は mailamb 拡張のためだけ**。他の挙動に影響しません。

---

## STEP 3: 拡張ファイルを配置

プロファイルフォルダの中に **`extensions/`** というフォルダがあるか確認（無ければ作る）。

受け取った `mailamb-x.y.z.xpi` を **`extensions/` の中にコピー** し、ファイル名を次のように変更:

```
mailamb@mailamb.local.xpi
```

**ファイル名重要**: 必ず `mailamb@mailamb.local.xpi` にする（別名だと認識されない）。

---

## STEP 4: Thunderbird を完全再起動

- 画面上部メニュー: Thunderbird → Thunderbird を終了（Mac: ⌘+Q / Win: Alt+F4）
- もう一度 Thunderbird を起動

---

## STEP 5: 拡張が有効か確認

TB メニュー → **ツール** → **アドオンとテーマ**

「アドオン」一覧に **`mailamb — AI下書き`** が出てて、トグルが**青（有効）**になっているか確認。

有効じゃなければトグルをクリックして有効化。

---

## STEP 6: 設定を入力

同じ「アドオンとテーマ」画面で、`mailamb` の **歯車アイコン** → **オプション** をクリック。

4項目入力:

| 項目 | 入力内容 |
|---|---|
| **Worker URL** | 管理者から受け取ったURL |
| **API Key** | 管理者から受け取ったキー |
| **スタッフID** | 自分のID（例: `tanaka`） |
| 新着メール受信時に AI下書きを自動で Draftsフォルダに保存する | ☑ チェック |
| 問い合わせ宛先 | 空欄のまま or 管理者指示（例: `info@yourcompany.com`） |

**保存** ボタンをクリック。

---

## STEP 7: 動作確認

### 確認A: メール表示欄にボタンが出る

- 受信トレイでなんでもいいメールを開く
- メール上部ツールバーに **🤖 のアイコン** が出てることを確認

出ない場合: ツールバーで右クリック → ツールバーをカスタマイズ → `AI下書きを見る` をドラッグして追加。

### 確認B: AI下書きが自動で作られる

- 問い合わせ用アドレスにテストメールを1通送る（別アカウントから）
- 1〜2分待つ
- **下書きフォルダ**を開く
- `Re: <元件名>` という下書きが**自動で出現**していることを確認

### 確認C: 下書きの中身

- その下書きをダブルクリックで開く
- 本文に AI生成の返信文（挨拶 + ヒアリング要項 + 末尾）が入っている
- 内容確認・編集して、送信するか判断

---

## よくあるトラブル

### 🤖 アイコンが出ない

- 拡張が無効化されている → アドオンマネージャで有効化
- TB再起動していない → 完全終了→再起動
- ツールバーに追加されていない → ツールバーをカスタマイズ

### 「Worker URL が未設定」エラー

- STEP 6 の設定を保存していない → オプションで入力+保存

### 下書きが自動で作られない

- スタッフIDが空 → 必ず入力
- 自動保存トグルがオフ → ☑ チェックして保存
- Worker URL/API Key が間違っている → 管理者に再確認
- CF Email Routing の転送設定が本番鯖にできていない（管理者側の問題）

### 認証ダイアログが出る

拡張自体には認証不要。送信時にメールサーバー（SMTP）のパスワードを求められた場合は、通常の TB メール設定で保存すれば以降聞かれない。

### 拡張を一時無効化したい

アドオンマネージャで `mailamb — AI下書き` のトグルをオフにするだけ。再度オンで元通り。

---

## アンインストール手順

1. アドオンマネージャで `mailamb` の `...` メニュー → **削除**
2. または `extensions/mailamb@mailamb.local.xpi` ファイルを削除
3. TB再起動

削除しても既存のメール・下書きには影響なし。Cloudflare側の下書き（KV）も残る。
