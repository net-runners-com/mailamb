■ タイムライン
----------------------------------------------------------------

0秒   顧客がメール送信
2秒   Cloudflare Email Routing 受信
3秒   mailamb-email Worker 起動
5秒   mailamb Worker 意図抽出 (AI)
8秒   RAG検索 (Vectorize)
10秒  LLM下書き生成
15秒  KV保存 + Gmail転送
20秒  スタッフGmailに届く
30秒  TB IMAPで同期
      ─── スタッフが見るタイミング ───
手動  スタッフがTBでメール開く → 🤖クリック
手動  下書き確認・編集
手動  送信ボタン

自動処理: 約15秒
人間判断: 2〜5分（内容次第）


■ データの流れ
----------------------------------------------------------------

受信メール
  ├─▶ 本文・件名・差出人・Message-ID抽出
  │
  ├─▶ 前処理フィルタ
  │     営業? → skip
  │     NG顧客? → skip
  │     採用? → skip
  │     ↓ 要返信
  │
  ├─▶ 意図抽出 (Workers AI)
  │     「何を聞いてるのか」1〜2文に要約
  │
  ├─▶ Embedding生成 (bge-m3)
  │     要約文→1024次元ベクトル
  │
  ├─▶ Vectorize検索 (cosine, top-5)
  │     類似テンプレ・過去対応ヒット
  │
  ├─▶ D1からメタ取得・R2から原本取得
  │
  ├─▶ LLM下書き生成 (llama-3.3-70b)
  │     [AI下書き] + 本文
  │
  ├─▶ KVに保存 (draft:<msgid>, 90日)
  │
  └─▶ 原メールを verified Gmail宛に転送
         ↓
        スタッフが受信
         ↓
        TB拡張が /api/draft/by-msgid/<msgid>
         ↓
        下書き表示
